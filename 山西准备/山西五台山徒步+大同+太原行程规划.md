

# 五台山计划


**Day1**
东台-护银沟-宽滩-南台-大南庄（可选择在南台扎营）
📍鸿门岩-东台 爬升约1h
📍东台-护银沟村 大约7h 7:00-14:15（雨天路特别滑）
📍护银沟-宽滩 大约6km全是水泥路（可坐车20r/人）
📍宽滩-南台 大约2h 15:40-17:30（天啊超级累，建议在护银沟村或宽滩补给一下再爬坡）
📍南台-大南庄 风景美丽路段 无爬升（提前戴护膝）
	
**Day2**
大南庄-狮子窝-吉祥寺-西台-中台-澡浴池
📍大南庄-狮子窝 约3h 8:00-10:20（全是爬坡好累）
📍狮子窝-吉祥寺 约1.5h 11:00-12:20（可选择走大路不用爬坡会快很多，走小路风景好）
📍吉祥寺-西台 约 1.5h 12:30-13:50（全是爬坡，到西台界碑可去包轻装上西台，延大路走风小，小路山脊线暴露风特别大）
📍西台-中台 约1h 14:20-15:30（爬坡爬坡，中台有免费白粥）
📍中台-早浴池 约1h 16:00-16:50（澡浴池的土豆丝特别好吃！我们在澡浴池扎营，日落也很好看！晚上风有点大，需要很多风绳）
	
**Day3**
澡浴池-北台-华北屋脊-鸿门岩-太原
📍早浴池-北台 约2h 8:00-9:40 （爬坡，北台海拔最高，会比较冷，盖最后一个章）
📍北台-华北屋脊 约1h 10:00-10:50（水泥路下坡，提前戴护膝，哈哈大佬买了个西瓜吃）
📍华北屋脊-鸿门岩 约2h 11:30-13:20（下坡+缓坡）
📍鸿门宴-忻州古城

**Day 3晚：五台山 → 忻州古城**
下午/傍晚到忻州，住古城附近。轻松逛：忻州古城
忻州西到大同

# 大同计划
**Day 4：云冈石窟 + 大同美食**  
🚄 出发大同，住大同古城附近。上午云冈石窟，建议约讲解，留 4 小时。下午回古城补华严寺、善化寺、九龙壁大同古城墙。  
🍜 吃：凤临阁烧麦、糖醋里脊、有萬喜、凯鸽酒楼、紫泥369、喜晋道刀削面。小红书上大同美食高频就是凤临阁、凯鸽、喜晋道、紫泥。

**Day 5：悬空寺 + 应县木塔 → 晚上去太原**  
🚗 这天建议包车，悬空寺要早去。路线：大同 → 悬空寺 → 应县木塔 → 大同/太原。  
🥢 吃：中途随便垫，晚上到太原吃老太原菜馆、认一力羊肉蒸饺，或者涮羊肉。

# 太原计划
**Day 6：晋祠 + 天龙山/植物园 + 太原夜生活**  
🌅 上午：晋祠  
建议 8:30-9:00 到，慢慢逛 2.5-3.5 小时。晋祠是太原最值得看的点，圣母殿、鱼沼飞梁、难老泉别漏。6 月是旺季，晋祠常规开放大概是 8:30-18:00。  
🍜 中午：晋祠附近吃饭  
可以吃晋祠老街的山西菜，或者回市区吃老太原菜馆。  
🌃 晚上：钟楼街 + 柳巷 + 食品街  
吃小吃和夜景。可以安排：认一力羊肉蒸饺、老鼠窟元宵、头脑、沾串、太原老酸奶。

**Day 7：双塔寺 + 太原古县城 + 晋阳湖**  
🌤️ 上午：双塔寺/永祚寺  
太原地标，节奏轻，拍照好看。比博物馆轻松，不会一直站着看展。  
🥢 中午：市区吃饭  
可以吃认一力羊肉蒸饺、老太原菜馆，或者找涮羊肉。前几天肉和面会很多，这顿别吃太撑。  
🏮 下午：太原古县城  
适合慢慢逛，建筑、街巷、拍照都比博物院更松弛。想吃小吃也方便。  
🌇 傍晚：晋阳湖公园  
如果返程不赶，去湖边走一圈，看日落。之后回酒店拿行李，去太原南站或机场。
