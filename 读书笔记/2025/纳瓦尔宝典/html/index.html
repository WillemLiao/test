CHAPTER 14

认识财富创造的原理

纳瓦尔宝典 · The Almanack of Naval Ravikant
赚钱跟工作的努力程度没什么必然联系。
与埋头苦干相比，更重要的是理解和思考。
📌 分清三个概念
🏦

财富

睡觉时也能赚钱的资产。
工厂、机器人、计算机程序、被投资的资金。

💵

金钱

转移财富的方式。
社会的信用符号，调用别人时间的能力。

🏆

地位

社会等级体系中的位置。
无视一味追求地位的人。

🌪️ 如何致富（不靠运气）
追求财富，而不是金钱或地位
创造财富和坚持道德可以兼得
必须拥有股权才能实现财务自由
为社会提供有需求但无从获得的东西，并规模化
选择有长期前景的行业和长期合作的人
所有的回报都来自复利
选择聪明正直的商业伙伴
不要跟愤世嫉俗的人合作
学会销售，学会构建，两技傍身，势不可当
用专长、责任感、杠杆效应武装自己
🔧 三种杠杆
👥

劳动力

让别人为你工作。最古老、争夺最激烈。

需许可
💰

资本

用金钱赚钱。需要运用专长和责任感获得融资。

需许可
💻

代码 & 媒体

不需要许可就能使用。新富阶层背后的杠杆。

不需许可
THE FORMULA
把自己产品化
"自己" = 独特性 + 专长 + 责任感
"产品化" = 杠杆效应 + 规模化

🏦 财富

CHAPTER 60

纳瓦尔的写作 · 生命公式

纳瓦尔宝典 · The Almanack of Naval Ravikant
这些不是定义，而是成功的算法。
💎 幸福公式
幸福 =
健康 + 财富 + 良好的人际关系
🏃 健康公式
健康 =
锻炼 + 饮食 + 睡眠
锻炼 = 高强度耐力训练 + 体育运动 + 休息
饮食 = 天然食物 + 间歇性禁食 + 植物
睡眠 = 不要闹钟 + 8~9小时 + 昼夜节律
💰 财富公式
财富 =
收入 + 财富 × 投资回报率
收入 = 责任 + 杠杆 + 专长
责任 = 个人品牌 + 个人平台 + 承担风险
杠杆 = 资本 + 人力 + 知识产权
专长 = 无法通过培训获得的知识
投资回报 = "买入并持有" + 估值 + 安全边际
