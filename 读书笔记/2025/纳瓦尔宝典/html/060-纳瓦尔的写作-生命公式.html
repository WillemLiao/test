CHAPTER 60

纳瓦尔的写作 · 生命公式

纳瓦尔宝典 · The Almanack of Naval Ravikant
这些不是定义，而是成功的算法。
💎 幸福公式
幸福 =
健康 + 财富 + 良好的人际关系
🏃 健康公式
健康 =
锻炼 + 饮食 + 睡眠
锻炼 = 高强度耐力训练 + 体育运动 + 休息
饮食 = 天然食物 + 间歇性禁食 + 植物
睡眠 = 不要闹钟 + 8~9小时 + 昼夜节律
💰 财富公式
财富 =
收入 + 财富 × 投资回报率
收入 = 责任 + 杠杆 + 专长
责任 = 个人品牌 + 个人平台 + 承担风险
杠杆 = 资本 + 人力 + 知识产权
专长 = 无法通过培训获得的知识
投资回报 = "买入并持有" + 估值 + 安全边际
